苫小牧埠頭野球部 Webアプリ v3.3
Supabaseクラウド移行準備版

【今回の変更】
・v3.2までの画面・成績表示を維持
・Supabaseクラウド保存に対応
・2026-09-28取得の既存バックアップ（選手20名、試合11件、予定17件、2026年度一括成績）を移行用SQLに内蔵
・管理者パスワード初期値を6161に変更
・管理者の変更操作はSupabase側でパスワード確認
・一般ユーザーの自分の出欠はクラウドへ保存
・Publishable keyのみを使用。Secret keyは使用しない

【最初にすること】
1. Supabaseのプロジェクトを開く
2. SQL Editorを開く
3. 同梱の「supabase_setup.sql」を全選択して貼り付ける
4. Runを1回実行する
5. 最後の確認結果で players=20 / games=11 / events=17 になっていることを確認する
6. その後、このフォルダのファイルをGitHub Pagesのリポジトリへ更新する

【重要】
・v2.39、v3.2、元のJSONバックアップは削除しないでください。
・Database password、Secret keyは誰にも送らないでください。
・このv3.3はSupabaseのSQL実行が完了してからクラウド本番として使用します。
