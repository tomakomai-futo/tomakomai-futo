# 苫小牧埠頭野球部 成績管理Webアプリ v3.0 本番公開用

## この版について
v2.39のデザイン・機能をベースに、本番公開しやすいPWA（ホーム画面追加・オフラインキャッシュ）として整えた公開用パッケージです。

- チーム名：苫小牧埠頭野球部
- 管理者モード：従来どおり維持
- 管理者のみ：選手・試合・打席・投球・予定・お知らせ・年間成績などを変更可能
- 一般ユーザー：閲覧、自分の選手設定、自分の出欠登録が可能
- iPhone SEを含むスマートフォン表示に対応
- Safariの「ホーム画面に追加」でアプリのように起動可能
- Service Workerによるオフラインキャッシュを追加

## 管理者について
管理者ログイン機能と管理者権限は従来どおりです。初期パスワードは「0000」です。公開前に「設定 → 管理者モード → 管理者パスワードを変更」で変更してください。

※現在の管理者認証はブラウザ側（localStorage）で動作します。URLを公開してチーム全員で同じデータを共有する場合、データ自体もブラウザごとに分かれます。チーム全員で同じ成績・出欠を共有する本番運用には、次段階でクラウドDB＋サーバー側認証を接続してください。

## 公開方法
静的Webホスティングに、このフォルダ内のファイルをそのままアップロードしてください。

必要ファイル：
- index.html
- app.js
- style.css
- manifest.json
- sw.js
- icon-192.png
- icon-512.png
- championship.jpg

GitHub Pages、Cloudflare Pages、Netlifyなどの静的ホスティングで公開できます。

## iPhone SEでの利用
1. Safariで公開URLを開く
2. 共有ボタンを押す
3. 「ホーム画面に追加」
4. 「Webアプリとして開く」が表示される場合はオン
5. 「追加」

## 注意
Service WorkerはHTTPS環境（またはlocalhost）で有効になります。GitHub Pages等で公開するとPWAとして利用できます。
